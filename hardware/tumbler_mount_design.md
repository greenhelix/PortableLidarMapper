# 텀블러 마운트 설계도 (초안)

> RPLIDAR C1 실측 후 치수를 채워넣는 작업 문서. 지금은 뼈대만 잡아둔다.

## 1. 기준 치수 (RPLIDAR C1 공식 스펙 기준, 실측 전)
- 라이다 본체 지름: 약 75mm
- 라이다 높이: 약 40mm (하단 케이블 커넥터 제외)
- 스캔 평면: 라이다 상단면 기준 수평, 360도

## 2. 조립 순서 (개념)
1. 텀블러/보온병 뚜껑을 제거하고 평탄화 디스크로 대체
2. 평탄화 디스크 중앙에 C1 장착 구멍(지름 75mm) 가공 또는 3D프린팅
3. 디스크 하단에서 USB 케이블을 텀블러 내부로 관통
4. 텀블러 내부 중~하단에 보드(Orange Pi 4 Pro) 고정 브라켓 배치
5. 최하단에 보조배터리 배치 (무게중심 하향)

## 3. 3D프린팅 파츠 목록 (예정)
| 파츠명 | 역할 | 상태 |
|---|---|---|
| 상단 평탄화 디스크 | 라이다 수평 고정 | 설계 전 |
| 보드(Orange Pi 4 Pro) 고정 브라켓 | 보드 진동 방지 고정 | 설계 전 |
| 케이블 정리 클립 | USB 케이블 단선 방지 | 설계 전 |

## 4. 검증 체크리스트 (프로토타입 완성 후)
- [ ] 텀블러를 기울여도 라이다 스캔 평면이 수평을 유지하는가
- [ ] 걷는 진동에서 SLAM 지도가 심하게 왜곡되지 않는가
- [ ] 보드 발열이 케이스 내부에 갇히지 않는가 (통풍 구멍 필요 여부)
- [ ] 배낭 측면 포켓에 들어가는 전체 높이/지름인가
