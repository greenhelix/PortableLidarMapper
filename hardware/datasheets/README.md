# 부품 데이터시트 모음

링크가 죽거나 회사가 문서를 내려도 로컬에 원본이 남아있도록 보관.

| 파일 | 부품 | 출처 | 비고 |
|---|---|---|---|
| `rplidar_c1_datasheet.pdf` | RPLIDAR C1 (라이다 센서) | SLAMTEC 공식, 2024-03-12 rev.1.1 | 마운트 나사 규격(M2.5, 43x43mm, 삽입깊이 4mm 이하) 여기서 확인 |
| `bno055_datasheet.pdf` | BNO055 칩 (IMU, CJMCU-055 모듈에 탑재) | Bosch Sensortec 공식 | I2C 주소, 센서 스펙, 레지스터 맵 등 |
| `orange_pi_4_pro_user_manual_v1.4.pdf` | Orange Pi 4 Pro (메인보드) | Shenzhen Xunlong(orangepi.net) 공식 | **40핀 GPIO 핀맵(3.15절)**, ROS2 Humble 설치법(3.26.1절), Docker 설치법(3.22절), 발열 모니터링 명령(3.14절) 등 실전 절차 다수 포함 |
