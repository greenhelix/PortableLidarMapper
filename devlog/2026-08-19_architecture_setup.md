# 2026-08-19 개발 로그 — 아키텍처 구조화

## 오늘의 목표
- 프로젝트 전체 아키텍처를 5개 레이어로 구조화
- 장비(Pi5) 도착 전에도 진행 가능한 개발 순서 확정

- 텀블러 마운트 하드웨어 설계도 초안 작성 (`hardware/tumbler_mount_design.md`)
- ROS2 워크스페이스 구조 확정: `lidar_mapper_bringup`(실행), `lidar_mapper_mock`(하드웨어 없이 개발용)
- 환경 세팅 스크립트(`scripts/setup_env.sh`) 초안 작성
