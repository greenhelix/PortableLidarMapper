  리스트, 로드맵, Phase 정의 섹션에 남아있던 "Raspberry Pi 5"/"Pi5" 표현을
  전부 "Orange Pi 4 Pro"/"보드"로 정정. 사용자가 지적("REAME Architechture

  놓쳤던 실수.
- **README.md에 아키텍처 설명 추가**: 다이어그램만 있고 말로 된 설명이 없다는
  지적에 따라, "소프트웨어 아키텍처" 섹션 신설 — 레이어드 구조/노드 단위
  분리/Docker 환경 독립성/어댑터 패턴 4가지 설계 원칙을 프로즈로 정리.
- **`hardware/tumbler_mount_design.md` 대폭 확장**:
  - 0번: 장비 장착 현황 표 (뭘 갖고 있고 뭘 안 갖고 있는지 한눈에)
  - 1번: 전원/파워 규격 — Orange Pi(5V/3A) + RPLIDAR C1(USB 버스파워)
    배선 우선순위, 배터리 용량 추정(10,000mAh급으로 1.5~2시간 추정), 구매 전
    체크리스트
  - 6번(신설): **백팩 측면 포켓 장착 예상 문제 4가지** — (1) 몸통에 의한 상시
    반쪽 가림(자기 그림자가 일시적이 아니라 영구적이 됨), (2) 걸음걸이로 인한
    주기적 다리 가림(마운트 높이가 하필 다리 스쳐가는 높이), (3) 포켓의 헐거운
    고정력으로 인한 흔들림/기울기, (4) 상단 돌출부의 물리적 충돌 위험. 각각에
    대한 대응 방향(각도 마스킹, 이동+몸 방향 전환으로 커버리지 확보, 마운트
    높이 절충, 충격 보호 캡)까지 기록.
- **`hardware/orange_pi_4_pro_bringup_risks.md`에 상세 설정 절차(5번) 신설**:
  OS 이미지 설치 → 네트워크/SSH → Docker 설치 → 프로젝트 이식(git clone +
  run_dev.sh) → GPIO/I2C 활성화(향후 IMU용, 정확한 핀은 실물 문서 필요) → 발열
  모니터링 명령어까지 Armbian 관례 기준으로 예상 절차 작성. 도착 후 실측
  명령어로 덮어쓸 것이라고 명시.
