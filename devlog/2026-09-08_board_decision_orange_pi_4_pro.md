# 2026-09-08 개발 로그 — 보드 결정: Raspberry Pi 5 → Orange Pi 4 Pro

## 오늘의 목표
- Pi5 가격 급등 문제를 해결할 대안 보드 조사 및 결정

## 진행 내용
- Pi5 실구매가가 LPDDR4 메모리 품귀로 정가 대비 크게 뛴 상태라 대안 SBC를
  사용자와 함께 하나씩 검토함 (AliExpress 실제 매물 스크린샷 기반):
  1. **Orange Pi Zero 3** (Allwinner H618, 쿼드코어 A53) — CPU가 slam_toolbox
     실시간 연산엔 너무 약함. 게다가 4GB 모델은 91,800원으로 더 강한 대안보다 비쌈 → 기각
  2. **Orange Pi 5 / 5 Max** (RK3588S/RK3588) — 스펙은 원래 추천이었지만,
     실제 매물이 상위 모델(Max, 8GB부터 시작)과 혼동되거나(26만원), 판매 이력이
     의심스러운 리스팅(1개 판매, 가짜 할인 패턴 "원가 511,500→60%할인")만 걸림
  3. **Orange Pi 4 Pro** (Allwinner A733, **2x Cortex-A76 + 6x Cortex-A55**,
     4GB LPDDR5, ₩74,800, 600+ 판매/4.6점) — 상세 스펙 확인 결과 빅코어(A76) 2개
     포함된 실제 쓸만한 구성. GPIO 40핀에 I2C/SPI/UART 지원(향후 IMU 확장에 유리),
     M.2 NVMe, USB-C 5V/3A 입력(보조배터리 구동 적합) 등 프로젝트에 필요한 확장성도 갖춤.
- **최종 결정: Orange Pi 4 Pro 4GB.** RK3588S(Orange Pi 5)보다 빅코어 2개
  적어(2 vs 4) 이론상 약간 아래지만, 검증된 판매 이력과 확장 포트, 그리고 지금
  가격이 비정상인 Pi5보다 훨씬 합리적인 가격이라는 점에서 실용적 최선책으로 판단.
- `README_ARCHITECTURE.md` 갱신: 0번 확정사항 표, 5.4 로드맵, 6번 리스크 섹션에
  보드 변경 사유 기록. `hardware/tumbler_mount_design.md`의 "Pi5" 언급도
  "보드(Orange Pi 4 Pro)"로 갱신(치수 자체는 아직 실측 전이라 변경 없음).

## 막힌 문제 & 해결
| 증상 | 원인 | 해결 방법 |
|---|---|---|
| 같은 "Orange Pi 4 Pro" 상품인데 리스팅마다 정보가 달라 보임 | 같은 보드를 여러 판매자가 각각 다른 스펙 배너(Wi-Fi5 vs Wi-Fi6)로 광고, 판매량/평점만 다름 | 판매량·평점 높은 리스팅을 신뢰 기준으로 선택 |
| "Orange Pi 5" 검색 결과에 상위 모델(5 Max, 5 Plus)이 섞여 나와 가격이 이상하게 비쌈 | Orange Pi는 같은 세대 안에 여러 등급(5/5 Plus/5 Max)이 있고 Max는 4GB 옵션이 아예 없음 | 모델명 뒤의 Plus/Max 여부를 반드시 확인하도록 정리 |
